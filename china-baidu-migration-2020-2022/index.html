核心元数据

数据名称全国人口迁徙数据（2020年1月1日-2022年4月22日）百度
时间属性2020年1月1日—2022年4月22日
空间范围全国；具体省市层级与行政单元以字段为准
数据内容迁入/迁出规模指数、流向比例或城市 OD；实际字段需核验
数值含义百度迁徙规模指数通常为相对指标，不应直接解释为绝对迁徙人口数
边界口径需核验行政区划版本、城市代码及跨年变更
数据格式常见为 CSV / JSON / XLSX 等表格格式，实际以文件为准
推荐软件Python pandas / NetworkX、R、QGIS、Gephi、PostGIS

使用前重点检查

  • 确认迁徙规模指数与流向比例的定义
  • 区分迁入、迁出及全国/城市统计口径
  • 不要把指数直接换算为绝对人口数量
  • 核对城市代码、行政边界和缺失日期
  • 考虑春节、疫情管控及节假日冲击
  • 检查采集方式、平台条款和引用要求
科研提示：2020—2022年横跨新冠疫情重要阶段，迁徙变化同时受到政策、节假日和平台用户结构影响。
指标提示：迁徙规模指数适合进行相对变化、排序和网络结构分析；绝对人口估计需要独立校准数据。
